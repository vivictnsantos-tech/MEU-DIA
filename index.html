                Sobre privacidade

                Todos os seus dados ficam salvos apenas neste dispositivo, no armazenamento local do navegador (LocalStorage). Nada é enviado para nenhum servidor.

                Limitações dos lembretes

                Como este é um aplicativo web, os lembretes funcionam enquanto o app estiver aberto ou em segundo plano no navegador. Com o app totalmente fechado, o navegador pode não conseguir disparar notificações — assim como qualquer site. Para lembretes confiáveis mesmo fechado, veja a opção "Levar para o celular" no menu Mais.
